# M7 — Authenticated Remote Service Management

Status: Complete.

The base-linked privileged management service provides physically provisioned TLS identity and bearer authorization. Application images remain independently compiled and deployed. See the [endpoint, trust and retry contract](../../../../src/firmware/management/README.md). Remote requests share the M4 developer-side package admission and M6 device storage/activation paths; device-side admission checks native descriptors and complete graph resource limits before service entry.

On the Feather V2, the hardware test installed a three-service graph over actual Wi-Fi, replaced the LED with a separately compiled faster version without reflashing the base, and observed a five-second health confirmation. A separately compiled failed-start button service consumed the bounded trials and automatically restored the healthy graph. All three services ended Running with successful results; remote logs contain LED transitions and IPC latency records.

Wrong credentials returned 401, excessive image length returned 413, a mismatched activation digest returned 409, and the absent firmware endpoint returned 404. Each preserved selection sequence/content. An unprovisioned TLS client rejected the certificate. Disconnecting halfway through an authorized upload preserved selection. Repeated stop and reactivation of the current good bank did not consume a candidate trial.

The real network test client ran in the local Linux Docker environment because direct macOS processes returned a local network routing error while Docker reached the device. This was a real TLS connection to the physical board, not a simulated server. No credentials, network names, keys or firmware binaries are included in evidence. All 17 host checks passed normally and with ASan/UBSan; authentication checks test every bearer byte and every truncated length. Evidence is in `evidence/m7`.

The endpoint is intended for a trusted development LAN. It does not isolate arbitrary native code, sign packages, migrate persistent service data, support kernel OTA, or promise uninterrupted service during staging. Management itself requires physical base replacement. Firmware and generated configuration contain private credentials and remain under ignored build output.
