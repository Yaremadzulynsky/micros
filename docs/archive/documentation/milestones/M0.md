## Validation

`cmake -S . -B build/host -G Ninja` and `cmake --build build/host` succeeded on macOS arm64 with Apple Clang 21.0.0, CMake 4.2.3, and Ninja 1.13.1. Both C17 and C++17 compile-only ABI checks passed with warnings treated as errors. Checks cover fixed result width, descriptor/API prefixes, layout, and header consumption. They do not prove MCU ABI compatibility, dynamic loading, or runtime behavior.

Local Markdown links and anchors were checked after migration. The selected ESP-IDF release and FreeRTOS documentation were verified upstream. No MCU firmware was changed, and no SDK was installed in M0.

## Deliberate Scope Limits

USB identity cannot determine the carrier board. The actual connected board is selected with no application GPIO enabled; carrier name/pin mapping is a prerequisite for M5 peripheral work. This explicitly narrows the board-selection deliverable rather than asserting an unverified board model.

The MCU compiler flags, executable format, relocations, usable executable memory, PSRAM capacity, and selected SDK build viability remain M1 evidence gates. ABI version 0 is provisional and must change revision if its contract changes. Timing thresholds are initial policy and require measurement; no hard-real-time guarantee is made.
