# Documentation archive

Moved out of the active documentation on September 14, 2026, at the owner's
request while the new reading path is developed. These files are retained for
reference and later reuse; some describe implemented contracts, while others
record historical proposals or observations. Archiving them does not make every
statement obsolete or verify it against the current code.

The active documentation is [the new introduction](../../index.md) and
[its topic pages](../../site). This archive is outside the MkDocs source
directory, so it is absent from the documentation site's navigation and search.

Relative links were adjusted for these locations. Recorded logs and evidence
retain their original contents, including historical paths and command output.
[relocations.json](relocations.json) maps every previous path to its new home,
including the current documentation plan, which moved to
[docs/planning](../../planning/documentation-plan.md).

To restore a file later, move it to its intended active location, update inbound
and outbound links, and add it to navigation only after review. Keep the archived
version's historical scope clear when reusing its content.
