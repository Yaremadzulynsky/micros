# Historical developer preview

**v0.1.0-preview.1 is a frozen release.** Its TOML declaration workflow differs
from current development. For the current local checkout, use [Quickstart](get-started.md).
{: .arch-intro}

The preview targeted host development and the ESP32 Feather V2 with 8 MiB flash.
Its original setup, build, deployment, and rollback instructions are retained
[at the release tag in the private development archive](https://github.com/Yaremadzulynsky/private_micros/blob/v0.1.0-preview.1/docs/site/developer-preview.md).
Use that tagged source and its prerequisites together rather than mixing current
syntax with old tools.

The [dated validation report](preview-evidence.md) records actual results and
coverage gaps for that preview. It is not evidence that later development changes
passed the same hardware checks.
