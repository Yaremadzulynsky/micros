# Contributing to Micros

Start with the [repository map](https://docs.meetmicros.com/site/contributing/#repository-map) and [agent instructions](AGENTS.md).
The [contributor guide](docs/site/contributing.md) is the authoritative source for
setup, host tests, documentation checks and contribution expectations.

Keep application code in independent projects. Include relevant regression
coverage and report verified behavior separately from hardware limitations.
Preserve unrelated changes and private operational state; do not commit generated
output, credentials or private base artifacts.

Original project code is [MIT licensed](LICENSE). Bundled components retain their
[upstream licenses](THIRD_PARTY_NOTICES.md).
